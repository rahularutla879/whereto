## Actionable decision

- **Compatible fixes available now:** none verified in supported Trixie for these23. When a stable package/backport is available, build/test/rescan only affected roles.
- **Demonstrably missing vulnerable component:** CVE-2026-82560 and9538. Preserve scanner source-package matches; record an explicit applicability decision, not a fabricated patch.
- **Current-contract conditional findings:**17. Retain operator-controlled files, no arbitrary SQL/files/commands, AESGCM12-byte nonces, TCP-only transports, C locale, non-root immutable app and privilege isolation. Owner/security disposition must acknowledge any host assumptions. A later feature must not reuse this assessment blindly.
- **Remaining independent technical judgment:** glibc strfmon/DNS-debug functions (19499/5435) and libstdc++ PBDS/aligned allocation (102010/95619). Request a bounded native-callsite/reachability decision or supported remediation; do not commission another architecture review or assert that response limits prove safety.
- No hosting-risk acceptance was made. Artifact-only publication approval is a separate, narrower decision and cannot permit live credentials, testers or provider spending.

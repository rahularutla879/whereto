## Rubric schema and review rules

Each case binds its original source UTF-8 SHA256 and canonical original case digest. Every dimension has `applicability`, `expected`, `sourceAnchors`, `basis`, and `independentReview`. Allowed states:

| State | Meaning / scoring |
|---|---|
| `supported` | Explicit reference assertion or separately labeled source-supported review expectation. Must be compared in its exact occurrence/scope/relation. This is not independent approval. |
| `not_applicable` | No such source requirement. Expected value is null. This is an **absence check**: inventing that requirement fails; it is not a wildcard allowing arbitrary output. |
| `awaiting_review` | Ambiguous or incomplete original expectation. Cannot produce a semantic pass for the affected case; retain minimum uncontroversial constraints and safe clarification. |

All 66 have complete **review records**, not complete independently reviewed gold. Original reference coverage remains 25 structured journey fixtures (defaults/provenance/scalars not all asserted), 26 partial ordinary checks, 15 prose references. The new source readings make omissions visible without modifying those originals. All 66 require independent adjudication, including N/A assertions and the compatibility of source-derived elaborations. Gold disagreement requires an explicit proposed amendment and owner review; frozen original files remain intact.

Twenty-four dimensions cover required/optional occurrences, named identities, mandatory/partial/flexible order, repeats, return origin, final destination/final visit/home ambiguity, whole-trip/travel-only/dwell limits and relations, dates/timezone, budget/transport, safe disposition, hallucinations, contradictions/injection, provenance, people, geography, shared place and deadlines. Labels are not venue IDs. `s0`, `s1`, etc. identify original source occurrences; repeated equal labels never merge. There is no blanket article stripping, category broadening, singular/plural repair or named-brand normalization. Only the already reviewed source-bound generic-article scorer may compare lower-case generic activity wording, preserving occurrence/status and exact named identity.

Evidence: stop provenance must belong to the correct source occurrence; optionality evidence must own the optional occurrence. An empty gold evidence placeholder is unspecified **exact wording**, not permission to omit required evidence. A nonempty asserted gold quote remains strict. Different source-supported span wording is allowable only where the existing reviewed comparator permits it. Exact named/brand identities and constraint relationships never become quote-insensitive. Edge proof requires correct indices/direction/cue scope; mere verbatim text or an acyclic graph is insufficient. V4's finite grammar must independently prove every proposed edge and every required reachability relationship. Unknown proof cannot be silently removed; safe unordered projection needs independent absence proof and preserves the raw error.

Correct source extraction with missing planning inputs may still require planning clarification. A field-only automatic check cannot assign full correctness.

**C — proposed guarded outcome:** independently inspect a copy of the raw strict output with frozen Ordering Policy V4 **before any legacy mutation**, and combine with the complete legacy validation result. This conservative evaluation does not implement the future single-authority runtime profile: legacy may still cause false rejection/delete start-finish in its own result. No graph is published or silently fixed. Endpoint transformations or unresolved raw/effective mappings prevent a production-readiness claim. If a valid future V4 profile needs to replace legacy order checks, that is a separately reviewed integration; Q1 does not implement it.

The executable replay checks complete structure, legacy disposition, raw immutability and independent ordering. **Full 24-field correctness remains a human-review contract**, not a newly implemented general semantic parser.
